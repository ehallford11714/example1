# Titanic

Titanic is an open-source, npm-installable agentic system with an MCP bus, service registry,
A2A policy engine, model ingestion/feasibility selection, task execution loop, memory (RAG +
episodic), constitutional guardrails, and sandboxed browser/code capabilities.
